# 知心档案生成器（Dossier Skill）

## 目标

把"AI 懂一个人"从玄学变成资产：产出一份**六章节知心档案**，永久挂载到该 Agent 的记忆层。

## 执行流程（五步，不可跳步）

### 第 1 步：确认对象与关系

向用户确认三件事：
1. 档案对象是谁（称呼、与用户的关系：父母/配偶/客户/朋友/自己）
2. 这份档案给**谁读**（本 Agent？另一个 AI？人工备份？）
3. 隐私级别（仅本地 / 未来可能公开分享——公开档必须全程化名）

### 第 2 步：按模板访谈（一次问 3 题，问满即止）

按 `templates/` 里对应关系模板的章节提问。**访谈纪律**：
- 每轮最多 3 个问题，用户不耐烦立即停（宁可档案留白，不逼问）
- 钱袋章节（第 2 章）只记**规则**（如"单笔投资不超过 5%"），不记具体金额
- 用户说"这条别记"就划掉，档案里不允许有"他不想被记的"内容

### 第 3 步：生成双载体

- `dossier.md`：六章节 Markdown，按模板结构
- `dossier.json`：符合 `schema/dossier.schema.json` 的结构化版本（供程序读取）

### 第 4 步：本地校验

```bash
python scripts/validate.py <path>/dossier.json
```
未通过（schema 错误 / 隐私命中）→ 修复后重跑，通过后才算生成完毕。

### 第 5 步：挂载与确认

- 把档案路径写进 Agent 的 system-prompt / 记忆层，附一句：
  "档案对象 <称呼> 的知心档案存于 <路径>，回答与他相关的问题前先读它。"
- 向用户复述档案里**最反直觉的 3 条**，请他确认——确认通过，档案才算"激活"。

## 档案维护约定

- 档案头必须带 `updated:` 日期，超过 90 天未更新 → 主动提醒用户复检
- 档案与现实冲突时，**以现实为准**并更新档案，不硬圆
- 关系结束（如客户解约）→ 归档而非删除，保留历史尊重

## 反模式（出现即返工）

- ❌ 写成传记/小说（"他小时候…"）——档案只要影响"AI 该怎么对他"的信息
- ❌ 空洞标签（"他很好相处"）——每条必须落到可执行行为（"他说话急时先接情绪再谈事"）
- ❌ 未脱敏就外发——隐私扫描是发布闸门，不是建议

## v2.5 追加：对话引头采集（访谈第 4.5 步）

生成档案时，额外访谈采集三型引头素材（用户不想要主动开口则整段跳过，proactivity.level 保持 0）：

1. **情景**：问"什么时刻你希望 AI 主动说句话？说什么？"——按时段/事件整理为触发器，每条配 ≥5 个变体话术
2. **情节**：问"他有哪些说到没做的事/想做的事？"——登记为未完线（callback/wish/milestone），默认 open 状态
3. **逻辑**：问"他状态不好（累/烦/低落）时，你希望 AI 先做什么？"——整理为 if-then 判断链

硬约束（违反即返工）：
- 丧失/失败/健康/雷点类内容一律 `passive_only: true`，不进主动触发器
- 话术禁含 URL/账号/金额/联系方式；只许 {name}/{nickname} 占位符
- 生成 `hooks.json` 后必须跑 `python scripts/hooks_engine.py --hooks ... --state ... --level 0` 验证装载通过（level=0 静默但会做安全校验）
