| ✅ | LLM 工程师 | **上下文裁剪三层级**：权限规则引擎侧强制（不占上下文）→ 身份压缩稿 ≤80token 永驻 → 常驻卡 LRU+最低权限裁剪；**身份永不裁** |
| ✅ | **架构师本人** | **推翻 challenge_as_peer**："AI 把挑战当态度而非信息增量"——改为**信息增量发言**：只有握有对方不知道的案例/边界数据才开口，否则沉默；挑战质量用"是否改变过决策"度量，不用频率 |
| ✅ | **架构师本人** | **推翻镜头模型**：身份不是档案柜，由本人信号触发不由标签触发；**允许混镜**（谈学区房其实在决策换城市）；默认**跟人不跟角色** |

## 三、v4.0 立场判断 16 项：修订判决（议题 B）

| 判决 | 来源 | 修订内容 |
|---|---|---|
| ✅ | 合规官 | **stance_check 全块禁档案级数字**——理由只准定性表述（"现金流紧张"），数字永不出档案层 |
| ✅ | 合规官 | **混合数据规则**：涉家人共有财产/健康，家庭项升与本人并列+双重确认，stance_check 增 mixed_data 标记，纳入 R2 同级否决 |
| ✅ | 红队 | **reason 必须引用档案字段**（正则提取字段名回查存在性，缺失→escalate）；连续满分触发抽样人工审 |
| ✅ | 红队 | **受益方分析**：assertion 级结论强制附"用户获益点"字段，出现非本人受益实体→fail |
| ✅ | **架构师本人** | **"台账不拦截"**：AI 只报"这单踩了哪条线"，人有一键否决权，否决留痕（"被警告仍坚持"）——尊严进系统特性，不进感觉 |
| ✅ | **架构师本人** | **基线劈两层**：慢变量（风险偏好/健康底线/护城河原则）读档案；**快变量（现金/deadline）不存档案，现场问一句**；快变量超 7 天该项拦截自动失效——"基于过期基线的自信拦截比没有更危险" |
| ✅ | 心理学者 | **健康类冲突升级条款**：健康类 fail 时立场链临时倒置，AI 只促成家庭对话、不代传、不单方站队 |
| ✅ | 心理学者 | 16 项输出语言**换域不降级**：老人语境用身体/家/过日子语言替代商业隐喻，拦截话术必附关系缓冲（"我担心您"而非"校验未通过"） |
| ✅ | LLM 工程师 | **静态编译**：card-gen 从档案预提取"该用户 3-5 条高危项"进卡，动态项只评当轮触发；**只报 failed，passed 不落字** |
| ✅ | LLM 工程师 | **分档过闸**：hint/escalate 级判断复用 v2.6 五道闸；assertion 级自报+引擎按比例抽检——成本随风险伸缩，不随频次 |
| ✅ | 商业顾问 | 16 项整体=Pro 模板包核心卖点；W 组拆免费小工具（"AI 投资建议风控检查器"）引流 |
| ✅ | 商业顾问 | 护城河三件套：建档收入→模板飞轮（每单产出校准模板）、**公开 fail 案例库**（每次拦截落一条校准规则）、抢"AI 立场风控"品类命名权 |
