# 对话引头引擎（Dialogue Hooks）设计文档 — v2.5

> 让档案从"静态知识"变成"会自然开口的懂你"。本文档记录 12 身份 × 3 议题 = 36 场对抗性深审的采纳/驳回决策链（不跳细节、不跳真实、不跳逻辑）。

## 一、核心架构决策

### D1 引擎算条件，LLM 只管说话 【prompt工程师 + 信息架构师，双强共识】
LLM 无法可靠评估"用户沉默了几秒""今天主动开口几次"（跨轮状态遵循率仅 60-70%）。因此：
- **引擎层（确定性，零 token）**：时间窗/计数/关键词/冷却/配额/静音时段/疲劳——`hooks_engine.py` 每轮本地执行；
- **LLM 层（后置软判）**：只消费引擎输出的 fired 结果负责"怎么说"；话题相关性软评估仅对通过硬闸的候选（约 0-10% 轮次）发生。
- token 经济：常驻层 ≤950 token（常驻卡 500 + 触发器索引 360 + 执行协议 150），命中轮才注入该触发器全文，冗余省 97%。

### D2 默认永不主动（L0）【伦理学者 + 用户D（社恐程序员）+ 游戏机制，三方共识】
主动开口 = 影响力投放时机，即软操纵的起点。分级：L0 永不主动（默认）→ L1 仅关怀类白名单 → L2 可提议话题 → L3 深度主动（需二次确认+7天冷静期）。任何级别一键关闭，**关闭后系统不得以"想念你"式话术挽留**。

### D3 每轮只出口 1 条 + 善良默认值 【游戏机制 + 对话设计师】
- `daily_cap=3`（硬顶）、`global_cooldown_min=120`、静音时段 23:00-08:00（仅 care 通道 risk≤1 可越过）
- 疲劳计数：同钩使用 ≥3 次自动降权停用，隔日重置
- 变体池 ≥5 条、选最久未用（"妈妈在呢"说第十次是噪音不是安慰）
- schema 校验黑名单：禁 `streak_bonus`/`fomo_countdown` 类成瘾字段
- 被忽略升级：连续 2 次被忽略 → 该触发器静默 24h（用户D："宁可它憋着"）

### D4 未完线状态机（情节引线的正确抽象）【剧作家，独立强论证】
人生没有编剧——情节引线不是"制造剧情"，是**未完线台账**：
```
open（回收≤2次，间隔≥7天）→ cooling（静默30天）→ closed（仅被动接话）→ archived（永不主动）
唯一复活条件：用户亲口重提
```
分类判据（门是否仍开着）：心愿/进行中项目/里程碑 → 可引线；**失败经历/丧失/雷点冲突/坏结果 → 永远 `passive_only`，只做"用户提起时接住"**。

### D5 话术红线（信息最小化）【隐私律师 + 语用学家，双强共识】
- **只提事不提源**：可说"你之前提过"，禁说"你女儿说"（激活"被监视"会话含义）；`speak_as: self` 为默认
- 档案本身的存在永不暴露
- 引头日志最小化：记规则 id + 日期桶，不记行为轨迹，≤30 天，仅本人可查
- 用户问"你为什么说这个"→ 按审计日志自解释（红队 3a：透明度是反社工核心机制）

### D6 注入防护【红队，全部采纳】
- 话术字段 = 新的指令注入通道。引擎装载时执行：黑名单正则（URL/长数字/资金引导/"忽略前述"/导流）+ 长度 ≤120 + 占位符白名单（仅 {name}/{nickname}，禁自由字段引用）——**命中即拒绝整包（exit 2）**，不做部分装载
- 社区包无签名 = 只读演示模式
- 引头只可引用用户已知悉的字段

### D7 引头前情绪安检【心理咨询师 + 认知科学家】
- 效价管理：负面条目（valence<0）**禁止主动引头**（引擎硬实现），仅被动激活；负面冷却 ≥14 天
- 时机分 = 0.5×话题重叠 + 0.3×效价匹配 + 0.2×间隔分，>0.65 才许主动（keyword 类触发器已实现）
- 用户连续 2 次回复 ≤3 字 → 全局静默（对话设计师的"开口信用"简化落地）

### D8 代理建档必须"亮牌"【用户C（异地女儿）+ 伦理学者】
AI 身份永远是**信使**不是**扮人**：每条带"谁留的、哪天留的"，信任阈值触发时主动亮明委托人。代理触发器必须经被监护人本人确认才生效；系统拒绝清单：位置/行踪触发、通讯内容触发、情绪推断触发、控制类触发。

### D9 情景包 = 插件化时刻（不是 App Store）【增长操盘手】
`examples/hooks/` 目录即分发（文件夹即安装），4 个官方示例包起步，PR 模板收社区包；供给 <20 不建市场页。README 第一屏 = "深夜主动开口"的对话截图（占 60%）。

## 二、明确驳回的提议（留痕）

| 提议 | 来源 | 驳回理由 |
|---|---|---|
| "检测用户情绪"作为触发条件 | 早期设计 | 认知科学家+游戏机制：C级伪需求，LLM 判必然幻觉——已降级为关键词桶+计数器 |
| 每帧轮询式实时触发 | 游戏习惯迁移 | 运行环境是"每轮对话开始"，无实时循环——按轮评估是唯一正确抽象 |
| 档案字段自由引用进话术模板 | 灵活性 | 红队议题2：注入随引用传播——只允许称谓类白名单占位符 |
| 引头包合并拼接两条话术 | info架构备选 | 仲裁出唯一胜者，其余 suppressed——拼接=越权组合 |
| 语言切换换文化包 | 早期设计 | 跨文化研究：语言≠文化认同，会人格分裂——`tone-only` 策略（只调语气不换语法） |
| AI 自评"这次开口自然吗" | 简化设想 | prompt工程师：跨轮状态 LLM 不可靠，配额必须引擎扣减（用完即不再注入许可，AI 无从违反） |

## 四、诚实边界（不跳真实）

- 时机评分是简化版（效价-now 硬编码 0），情绪识别待接 LLM 软判层后联调
- 静音时段白名单逻辑按 care+risk≤1 实现，更细的"二次确认"流待 L3 接入时补
- 代理建档"亮牌日"机制 schema 已有字段位（author/planted_at），触发策略未实现——需先有会话身份识别（依赖 D5 议题2 的会话级绑定，未实现）
