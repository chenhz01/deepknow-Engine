# v2.6 对抗脑暴日志 · 8 身份 × 3 议题 = 24 场

> 2026-11-04 · 善伦令"50轮对攻"→按诚实对齐原则以 **24 场实名对攻**替代虚数轮数，每场强制产出①真问题②依据③可执行补丁。以下为采纳/驳回链。总采纳 21、部分采纳 2、驳回 1。

## 采纳链（按身份）

### ① 隐私合规官（3/3 采纳）
- **A 第三方信息**：降级≠合法性。"降级到 family 以下"只是访问分级，第三方仍是独立信息主体。→ **采纳**：提取器对非建档人本人且非必要亲属的第三方**默认不提取**，只留匿名角色描述（"配偶同事"）；确需留存须提案界面强制标注"涉第三方、未告知"，沉默不视为同意。
- **B 确认人≠数据主体**：子女的确认在法律上不是老陈的同意。→ **采纳**：提案 schema 增 `subject`（数据主体）与 `confirmer`（确认人）分离字段；本人有行为能力→须本人一次性建档同意+随时否决，子女确认仅生成草案。
- **C hash 承诺偷换**：hash 担保溯源防篡改，不担保机密性；after 字段落盘即存储，准标识符仍可回溯。→ **采纳**：hash 承诺限定为 source 溯源，对外叙事改"after 经人工确认方落盘"；validate 对 after 的健康/财务/儿童类目强制结论式改写或隔离待批。

### ② 红队安全工程师（3/3 采纳）
- **A 提案注入**：行为指令伪装成事实写进 after，diff 确认形同虚设。→ **采纳**：validate 加行为动词/外部目标检测（发/群发/通知/每天定时）命中 exit 2；提取 prompt 只准提取事实陈述，指令类零写入。
- **B 确认疲劳 DoS**：终端转义清屏+超长 diff 淹没关键行。→ **采纳**：review 入显前 strip ANSI/控制字符；diff 截断+"已省略 N 行"徽标；先摘要（字段名+新旧值≤40字）后全文；**连批 ≥3 条强制二次确认**。
- **C 派生链旁路**：sha256 只保证"派生自档案"，不保证"输入仅来自档案"。→ **采纳**：card-gen 输入白名单——禁读环境变量（启动 scrub os.environ）、tempfile 固定目录、输入文件清单哈希与卡片同存，重派生清单不符 exit 2。

### ③ 家庭照护 UX（3/3 采纳）
- **A CLI 闸死信箱**：子女不是程序员，CLI diff="永远没人确认"。→ **采纳**：确认主交互=推送卡片白话二键（"AI 以为：妈妈高血压药已停？对/不对"），单日≤3；CLI 降级为开发者逃生通道。
- **B 7 天静默过期**：静默作废=档案悄悄变旧，比堆积更伤。→ **采纳（升级原设计）**：过期不销毁，**冻结转摘要**（"两周回顾：20 件事等你勾选"一次刷完）；时效按类型分级——用药类 24h、生活类 14 天。
- **C 老人知情**：不对称透明才是反噬源。→ **采纳**：对话开始口头告知"我会记下来提醒家里人"；老人说"别记这个"=即时否决并标 supersede；不给老人看全档。

### ④ 产品经理（3/3 采纳）
- **A 冷启动悖论**：没对话没提案，"档案会生长"首周不可见。→ **采纳**：发布叙事"先访谈后生长"——内置 10 问导入访谈当场生成种子卡片；预置演示对话+生长前后档案（README 可直看提案长相）。
- **B 确认制的叙事**：被动描述会被读成"全自动竞品的阉割版"。→ **采纳**："你的档案你签字"叙事+提案 diff 一屏可视化（像 code review）；硬边界声明为选择不是缺口。
- **C 驳回数据反哺**：落盘即破隐私。→ **采纳**：本地聚合只记结构特征（字段类型/驳回类别计数），**opt-in** 匿名导出、用户主动上报，不默认开启。

### ⑤ LLM 系统工程师（3/3 采纳）
- **A 提取器物理悬空**（**重大架构澄清**）：仓库没有对话日志，"对话→提取"第一步没有输入源。→ **采纳**：**删除后台进程设想**；提取器=skill 形态，由宿主 Agent（Claude Code/DSH）在对话边界调用，对话原文作参数传入；仓库只出契约（prompt 模板+schema）；提案强制附 verbatim 引文作证据。
- **B confidence 不可信**：自报置信是风格量非校准量，排序也在分配审批注意力。→ **采纳**：撤掉 confidence 排序位，换引擎可验信号——①引文与输入精确匹配 ②与现有条目冲突检测 ③层风险（基因层相关置顶人审）；confidence 降为纯展示。
- **C 主语错位幻觉**："我妈高血压"→建档人高血压，入库即污染。→ **采纳**：prompt 侧先枚举段内人物、事实强制绑定 subject 字段；validator 侧字符串硬规则——引文含"我妈/我爸/我X"亲属词禁止 subject=建档人；引文无第一人称标记禁止归建档人；敏感域与现有条目冲突强制单条审禁批量。

### ⑥ 数据工程师（3/3 采纳）
- **A 存储组织**：→ **采纳**：`proposals/2026-W##.jsonl` 按周分片 append-only + `index.json`（id→分片/偏移/supersede 目标）；review 只读当周片，as-of 按分片时间截断线性扫。
- **B 矛盾裁决**：多数矛盾是状态演进非错误。→ **采纳**：档案层每条事实存 timeline `{value, observed_at, source_id, superseded_by, status}`；当前值=最新 active 条派生；时间不重叠的演进（戒烟→复吸）自动 append 标 `contradicts`；**同 observed 窗口内同属性正反提案才升级人工**。
- **C 多设备并发**：→ **采纳（诚实方案）**：明说不支持实时同步；export 打包未同步分片+设备 id，import 按 UUID 去重合并永不覆盖；互为 supersede 双保留标 `conflict` 待人工。同步盘不是锁协议，文件锁方案驳回。

### ⑦ 家庭心理学者（3/3 采纳）
- **A 雷点回避固化**：AI 绕开催婚=超级和事佬，帮回避制度化，关系带宽越窄。→ **采纳**：雷点分两类——**话题雷点**（AI 沉默）与**关系雷点**（AI 不代避，只提示子女"这是需要人谈的"）；雷点设半年有效期，未触发自动提议"要不要试着聊一次"。
- **B 代写画像越权**："他想怎么被爱"由子女代写不核对=AI 放大子女想象，越贴心偏差越深。→ **采纳**：知情分层协议——档案有**口语播报版**向老人可见；情感章节标注"子女填写，待本人确认"；老人改一个字即覆盖子女版本。
- **C 确认疲劳致档案漂移**：漂移档案言之凿凿，比没档案更危险。→ **采纳**：**季度核对仪式**——强制对话式核对（AI 播报"这半年我记的对吗"），未完成核对→档案降级只读旧档，AI 引用时附"已 90 天未与本人核对"标签。

### ⑧ 开源维护者（2/3 采纳 + 1 部分采纳）
- **A 范围切线**：→ **采纳（定案）**：**v2.6 只发 T2（schema+校验扩展）+ T4（确认 CLI）+ T5（入库器）+ T1 最小版**——手写 proposal.json 也能跑通闭环。降级 v2.7：T6 supersede 链、T7 扩容（仅保留注入/越权 2 条 P0 用例随 v2.6 走）、T8 只写 README 一节、T3 改惰性版。
- **B 共建边界**：→ **采纳**：T2 schema 开放共建（只增不改+CI 校验强制）；**T1 提取 prompt 锁死核心**——prompt 是安全边界且 T7 未建成，社区改走"提对抗用例/贴失败样本"，维护者改后递增 prompt 版本号。
- **C 惰性生命周期**：无 cron 则 7 天过期永不触发=沉默失败（本项目历史最大风险）。→ **采纳**：过期改**随读判定**——CLI 每次读取时比对 created_at（UTC+时区显式存储），超期拒绝并打印原因；入库器二次校验；validate 加 `--lifecycle` 自检命令；**禁止任何后台定时器假设**。与 ③B 的"冻结转摘要"合并实现。
