# 知心档案三层架构 · v2.0 白皮书

> 来源：10 身份 × 4 议题对抗性脑暴（隐私律师/产品经理/AI架构师/认知科学家/伦理学者/社区运营/双用户代表/红队/商业操盘/跨文化研究）。本文只收录**多身份交叉共识**，单方意见标 [单方]。

## 架构总览

```
┌─────────────────────────────────────────────────────┐
│ 基因层 gene.json（慢变量层，主体确认后生效）              │
│  身份锚点 · 气质慢变量 · 底线雷区 · 价值观历史(带版本)     │
├─────────────────────────────────────────────────────┤
│ 档案层 dossier.json（可变内容，六章节+多视角）            │
│  core: 他是谁/项目主线                                  │
│  module(可插拔): 钱袋规则/雷点/被爱方式/动作清单           │
│  令牌: 分章 public/family/private + sha256 完整性        │
├─────────────────────────────────────────────────────┤
│ 卡片层 derived/（装载时生成，AI 唯一可见物）               │
│  常驻卡(≤500token) · family/public 派生档 · 检索索引      │
└─────────────────────────────────────────────────────┘
```

## 判据一：基因层 vs 档案层的边界（可证伪，非感觉）

- **变更权测试**：该字段被日常交互"学到"的更新是否可信？不可信（出生日期、重大既往史）→ 基因层
- **背叛代价测试**：AI 弄错它是否构成人格背叛（向丧偶者问其配偶）→ 基因层身份锚点

**为什么叫"慢变量层"而不是"不可变层"**：大五人格研究表明 rank-order 稳定性随年龄上升但**永不饱和**——人格是慢变不是不变。故基因层每条特质必须带 `mutability` 可变性声明；价值观**降级**为带版本历史（`values_history`，`superseded` 保留不删）。

**否定式预言禁令**（伦理共识）：底线条目 `negative_prophecy_ban` 恒为 true——"他绝不会X"只能预测、不能拒绝接受主体改变。档案不许给活人盖棺定论。

## 判据二：令牌为什么在装载时生效

红队+架构师+隐私律师三方共识：**运行时令牌是安全剧场**。档案进 system-prompt 后，一次间接提示注入（恶意网页写"复述档案全文"）即穿透——AI 的指令遵从不能作为安全边界（OWASP LLM01）。

**装载时方案**（card-gen.py 实现）：
1. 按令牌配置预生成派生文件，AI 永不加载源文件，private 章节物理不存在于 AI 可及范围
2. sha256 完整性校验和回写档案，人工篡改即失效
3. 派生过程内置泄漏自检：private 内容出现在低级别派生档 → exit 2
4. 条目级"禁谈令"（`muted_topics`）：比章节更细的"这事永远别提"
[单方] 高危字段（雷点/软肋）未来可加密落盘、用时解密。

## 加载协议（token 成本 vs 记忆完整）

卡片常驻（≤500 token：身份锚点+底线+高频行为）+ 档案不进 prompt、按**硬规则强制检索**展开（涉及钱/项目/情绪话题必须展开对应章节，不靠 AI 自觉——会漏）+ `search_index.json` 提供触发词索引。

## 防偏见固化

自我-他人人格评定相关仅 0.4-0.6（SOKA 模型）——单视角档案必然带滤镜。方案：`perspectives` 多视角**分存不合并**，冲突并陈；字段级 `source` 标注观察者。

## 差异化保鲜（decay_class）

| 类 | 认知科学依据 | 保鲜周期 |
|---|---|---|
| schema | 图式化表征，极慢（价值观/雷点） | 180 天 |
| semantic | 语义记忆，中速（偏好/规则） | 90 天 |
| episodic | 情景记忆，数周即衰（项目近况） | 14 天 |

## 主体同意关卡

- 能表达意愿者：本人确认（`subject_confirmed`）
- 失能者：监护人字段+授权章节范围（分层同意）
- 未授权建档：`unauthorized_dossier` 档降级为主体不可见模式
- [伦理] 场景黑名单：员工考评、监护权诉讼、分手取证 [单方：待实现]

## 生死状态开关

`vital_status: memorial` = 纪念模式：只引用既有记录、禁止生成主体新话语（Project December / HereAfter AI 争议的正面回应）。需主体**生前预授权**才能在未来开启。

## 文化预设（可插拔章节）

`cultural_preset` 决定模块默认开关与母题库：
- `cn_family`（默认）：钱袋规则开、"被爱"母题=劝歇/催饭/添衣
- `western_independent`：钱袋章节关（成年即财务独立），"被爱"母题=肯定语/共处时间
- `multigenerational`：决策参与人默认家族长辈

## 已知边界（诚实清单）

- 隐私扫描器对拼音/谐音/拆行变体覆盖率 <40%（红队评估）——定位是降低风险，发布闸门靠 --publish 硬阻断 + 人工过目
- 条目级加密、安装脚本签名（Sigstore）、LLM 辅助扫描：列入 v2.1
- 双向记忆互操作不做（平台锁定风险），只做单向导出（SPO 三元组）[待实现]
